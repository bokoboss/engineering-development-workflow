# Philosophy

## The goal is not autonomous coding

The goal is **reliable engineering delivery with efficient use of human and model capability**.

A strong system moves expensive ambiguity-resolution work upstream, turns execution into bounded packets, and makes completion objectively inspectable.

## Core beliefs

- Repository state beats conversational memory for project truth.
- A good prompt cannot replace missing engineering evidence.
- A powerful model should not be used to compensate for avoidable ambiguity.
- Cheap execution is valuable only when it reaches verified completion without excessive rework.
- Parallelism is an optimization, not a virtue.
- UX correctness is part of engineering correctness when software mediates engineering decisions.
- Human approval remains appropriate for protected decisions.
- `BLOCKED` is better than a fabricated PASS.
